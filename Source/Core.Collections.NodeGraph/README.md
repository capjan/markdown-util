# Core Node Graph

`Node Graph` is a simple graph data structure, as the name suggests.

## Structure

- Node Graph is a `general tree` structure.
- A node can have any number of children.


## Features

- Every node in the graph has an optional parent and zero or more children.
- Visitors can traverse the graph in `depth-first` or `breadth-first` order.
- Its interface-based design makes it easy to integrate with existing classes.
