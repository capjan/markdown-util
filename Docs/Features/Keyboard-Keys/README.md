# Keyboard Keys

Add shortcuts right in a sentence. MDU turns them into keycaps.

Write `++cmd+s++` to show ++cmd+s++. Wrap the whole shortcut in `++` and join keys with `+`.

Save with ++cmd+s++, undo with ++cmd+z++, and redo with ++cmd+shift+z++.

## A few simple rules

- Type letters and numbers directly: `++ctrl+c++` → ++ctrl+c++.
- Key names are case-insensitive. Common modifiers include `cmd` / `command`, `opt` / `option`, `ctrl` / `control`, and `shift`.
- Use key names for punctuation: `period` for `.` and `plus` for `+`.
- Put a custom label in quotes: `++cmd+"Any key"++` → ++cmd+"Any key"++.

Text between `++` that is not a shortcut stays inserted and underlined, as in `++new text++`.

## Need another key?

Modifier keys show their familiar symbols: ++cmd++ ++opt++ ++ctrl++ ++shift++. Arrow keys show only their arrows. See the [keyboard key reference](./Reference.md) for all supported key names and aliases.
