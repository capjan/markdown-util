# Features

## Main Features

- [Code Blocks](./CodeBlocks/README.md) - Displays fenced code blocks with syntax highlighting
- [Formatting](./Formatting/README.md) - Shows common Markdown formatting supported by Markdig
- [Sidebar](./Sidebar/README.md) - Describes the generated sidebar and how to control its order
- [Tables](./Tables/README.md) - Examples of rendered Markdown tables
- [Diagrams](./Diagrams/README.md) - Renders Mermaid flowcharts and sequence diagrams, PlantUML component diagrams, and context diagrams to static SVG that follows the light and dark theme
- [Callouts](./Callouts/README.md) - Highlights notes, tips, and warnings with GitHub-compatible alert syntax
- [Keyboard Keys](./Keyboard-Keys/README.md) - Shows keyboard shortcuts such as `++cmd+s++` as keycaps with their usual symbols
- [Math](./Math/README.md) - Renders GitHub-compatible math syntax as static SVG
- [Media Links](./MediaLinks/README.md) - Embeds standalone YouTube and Vimeo links as video players
- [Icons and Emojis](./Icons-and-Emojis/README.md) - Adds more than 17,000 icons, colored logos, and GitHub emojis with shortcodes, with a search that copies them to the clipboard
- [Images](./Images/README.md) - Renders Markdown images, copies linked local image files, and checks local image paths
- Breadcrumb navigation is generated from the Markdown file structure during rendering; source files remain unchanged.
