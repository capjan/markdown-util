# Features

## Main Features

- [HTML Renderer](./HtmlRenderer/README.md) - Renders static HTML pages from Markdown files
- [Sidebar](./Sidebar/README.md) - Describes the generated sidebar and how to control its order
- [Diagrams](./Diagrams/README.md) - Renders Mermaid flowcharts, sequence diagrams, and context diagrams to static SVG that follows the light and dark theme
- [Admonitions](./Admonitions/README.md) - Highlights notes, tips, and warnings with GitHub-compatible alert syntax
- Breadcrumb navigation is generated from the Markdown file structure during rendering; source files remain unchanged.
