# Swagger Petstore OpenAPI 3.0 example

This page renders the [Swagger Petstore - OpenAPI 3.0](https://petstore3.swagger.io/) sample API. It describes the same pets, store orders, and users as the [Swagger 2.0 Petstore example](openapi-petstore.md), but uses OpenAPI 3.0 with reusable components, request bodies in several media types, and enums.

The page needs only this front matter:

```yaml
---
openapi: ./openapi-petstore-v3.json
---
```

`openapi-petstore-v3.json` is the specification from `https://petstore3.swagger.io/api/v3/openapi.json`, formatted with indentation. The specification declares the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0.html).
