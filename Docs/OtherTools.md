# Other Tools

Static site generators for Markdown documentation are not new, and many good solutions already exist.

Please note:

- This project was created to follow the principle of "eating our own dog food" and should be understood in that context.
- This tool is tailored to the author's current needs and may introduce breaking changes at any time. This policy will remain in place until the project reaches an appropriate level of production readiness.
- Check out the other tools if you are looking for an established project with a much larger community.

## Other Tools

This is a short list of interesting free alternatives from the author's perspective. It is not intended to be comprehensive.

- [Docusaurus](https://docusaurus.io) - Free documentation platform built with [React](https://reactjs.org/) by Meta, with [source code on GitHub](https://github.com/facebook/docusaurus).
- [MkDocs](https://www.mkdocs.org) - Free Python-based documentation generator, with [source code on GitHub](https://github.com/mkdocs/mkdocs/).
- [VuePress](https://vuepress.vuejs.org) - Free Vue-powered static site generator, with [source code on GitHub](https://github.com/vuejs/vuepress).
