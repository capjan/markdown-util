# Setup

Install MDU globally as a .NET tool:

```sh
dotnet tool install --global mdu
```

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). For [repository-local installation](DotNet-Tool-Installation.md) or a [portable executable](Portable-Installation.md), see the detailed guides.
